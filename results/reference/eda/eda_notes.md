# Анализ датасета металлических дефектов

Состав train/val/test совпадает с данными завершённого эксперимента DETR.
При анализе исходные изображения, разметка, разделение и веса не изменялись.

| Выборка | Изображения | Объекты | Изображения без объектов |
|---|---:|---:|---:|
| train | 752 | 985 | 0 |
| val | 161 | 233 | 0 |
| test | 162 | 226 | 0 |

| Класс | Train: объекты | Val: объекты | Test: объекты |
|---|---:|---:|---:|
| deburring | 34 | 6 | 3 |
| inclusion | 243 | 84 | 74 |
| rolled_pit | 40 | 4 | 16 |
| silk_spot | 572 | 114 | 107 |
| waist_folding | 96 | 25 | 26 |

В train больше всего рамок класса silk_spot (572), меньше всего класса deburring (34).
Число изображений с классом и число рамок считаются отдельно: на одном изображении может быть несколько объектов.

Малочисленные классы в val/test:
- val: deburring — 6 изображений, 6 объектов.
- val: rolled_pit — 1 изображений, 4 объектов.
- test: deburring — 3 изображений, 3 объектов.

Для таких классов выводы по отдельным AP/Recall нужно делать с учётом малого числа примеров.

Проверка дубликатов:
- Одинаковые файлы: 0 групп, из них 0 между выборками.
- Одинаковые RGB-пиксели с одинаковым размером: 0 групп, из них 0 между выборками.
- Поиск визуально похожих, но не идентичных изображений в эту проверку не входит.

Среднее и стандартное отклонение RGB рассчитаны по всем пикселям только train в диапазоне [0, 1].
Mean: [0.353065, 0.353041, 0.35297]. Std: [0.162094, 0.162038, 0.16199].
Это описательная статистика: ранее выбранная нормализация моделей сохранена.

Размеры рамок представлены в пикселях и относительно ширины, высоты и площади изображения.
Порог «меньше 1% площади изображения» используется только для описания данных.
Статистика не доказывает причину различий качества моделей.

Файлы: class_distribution.csv, images.csv, boxes.csv, eda.json; графики находятся в figures/.
Примеры на train_examples.png выбраны по порядку файлов, по одному для каждого класса.
