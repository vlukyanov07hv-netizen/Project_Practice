## Что это?

Данные проекта: [c5data2](https://www.kaggle.com/datasets/niclinn/c5data2).
В исходном наборе изображения лежали в папках классов, а рамки — в XML Pascal VOC.
Рабочая версия содержит изображения и TXT-разметку YOLO для пяти классов.

| ID | Класс | Объекты train / val / test |
|----|-------|---------------------------|
| 0 | deburring | 34 / 6 / 3 |
| 1 | inclusion | 243 / 84 / 74 |
| 2 | rolled_pit | 40 / 4 / 16 |
| 3 | silk_spot | 572 / 114 / 107 |
| 4 | waist_folding | 96 / 25 / 26 |

## Как восстановить?

Скачай `dataset.zip` из Releases этого репозитория, положи в `release_assets/` и выполни из корня проекта:

```bash
python restore_release_assets.py --assets release_assets
```

Архив содержит `data/raw/images/train`, `val`, `test` и соответствующие папки `data/raw/labels/`.
Контрольные суммы каждого изображения и TXT-файла хранятся в `results/reference/eda/*_manifest.json`.
Сборщик для Windows переносит эти оригинальные списки и сверяет по ним датасет.

## Почему не создавать разбиение заново?

Исторический конвертер использовал `random.shuffle` с seed 42 после обхода папок через `os.listdir`.
Порядок файлов может различаться между компьютерами. Повторный shuffle не гарантирует тот же train/val/test.
Для воспроизведения используются готовый архив и сохранённые списки файлов.

В текущей рабочей версии исправлена одна обучающая рамка `debur_img_003`: отрицательная координата ymin ограничена границей изображения.
Test не изменялся. Ранние YOLO, Faster R-CNN и SSD обучались до этого исправления, DETR и EfficientDet — после.

Исходный `src/dataset/convert_voc_to_yolo.py` сохранён как исторический код первого этапа с исходными Windows-путями.
Для оценки через `main.py` он не запускается. Рабочие пути оценки задаются относительно корня проекта в `configs/pipeline/`.

Источник и условия использования данных указаны на странице c5data2. Лицензия исходного датасета не заменяется лицензией кода проекта.
