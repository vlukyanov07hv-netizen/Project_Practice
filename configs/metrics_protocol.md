# Общий протокол оценки

- Test: 162 фиксированных изображения / 226 объектов, пять классов.
- Ground truth и predictions: XYXY в пикселях исходного изображения.
- Predictions собираются от confidence=0.001. Для YOLO/Faster R-CNN/SSD:
  NMS IoU=0.7, max detections=300 на изображение. DETR: 100 queries, NMS не применяется.
- YOLO: imgsz=640, letterbox, rect=False, batch=4, FP32. Faster R-CNN:
  штатный min=800/max=1333. SSD: штатный 300x300. DETR:
  shortest_edge=512, longest_edge=1024, официальный processor, FP32.
- Scorer ограничивает detections до 100 на класс и изображение.
- Для каждого класса/IoU предсказания сортируются по убыванию score.
  Совпадение — лучший ещё свободный объект того же класса, IoU ≥ порога;
  один объект не используется дважды. На точных равных IoU выбирается
  более поздний индекс объекта, как в прежнем проверенном scorer.
- AP использует 101 точку recall, монотонную оболочку precision и площадь
  без разделения на small/medium/large. Нет crowd/ignore разметки.
  Это зафиксированный общий scorer, а не заявление о запуске pycocotools.
- mAP50 — среднее AP по классам при IoU=0.50; mAP50-95 — среднее
  по классам и порогам 0.50,0.55,…,0.95. Класс без GT не входит в среднее AP.
- Precision/recall/F1: micro, confidence=0.25, IoU=0.50.
  В `per_class` также сохраняются support и метрики отдельных классов.
- Обязательный ключ `mAP` в `results/metrics.json` означает **mAP50**;
  `mAP50_95` сохраняется отдельно. Значения — доли [0,1].
- Confidence/IoU не подбираются по test. Веса выбираются по val либо
  фиксированной финальной эпохе старого эксперимента; происхождение
  каждого checkpoint указано в `configs/experiment_provenance.json`.
- Различия разрешений, длительности обучения, начальных весов и железа
  не позволяют трактовать таблицу как сравнение при одинаковом бюджете.

## Зафиксированный GPU-протокол v1.1

Настройки заданы явно в configs/runtime_protocol.json и runtime_backend
в YAML. Параметры до и после inference сохраняются в metrics.json
и environment.json. Для SSD подтверждено, что переключение cuDNN
deterministic=False → True изменяет confidence и AP при прежних весах.
В текущем сравнении используется повторённая оценка с True:
mAP50=0.0354850895702933, mAP50-95=0.01115796551018411.
Precision/Recall/F1 и TP/FP/FN остались прежними. Старые значения
сохранены отдельно с причиной пересмотра; scorer не менялся.
Выбран существующий режим pipeline после проверки повторяемости,
без оптимизации режима по test mAP.
